INTRODUCTION                                        *extensions-introduction*

extensions.nvim recreates the UX of VSCode's "Extensions" sidebar tab inside
Neovim: browse a catalog of Neovim plugins, search/filter it, view details,
and install or remove plugins with a keypress. It manages plugins through
lazy.nvim, using its own spec file so it never touches other config files.

==============================================================================
REQUIREMENTS                                        *extensions-requirements*

- Neovim >= 0.9.0
- lazy.nvim         (https://github.com/folke/lazy.nvim)
- nui.nvim          (https://github.com/MunifTanjim/nui.nvim)

==============================================================================
SETUP                                                      *extensions-setup*

Add it as a lazy.nvim plugin spec, e.g. in `lua/plugins/extensions.lua`: >lua
    return {
      "DevDanielAlvarez/Extensions.Nvim",
      dependencies = { "MunifTanjim/nui.nvim" },
      cmd = "Extensions",
      opts = {},
    }
<
`opts = {}` triggers `require("extensions").setup(opts)` automatically. You
may also call it yourself:
>lua
    require("extensions").setup({
      catalog_path = nil, -- see |extensions-configuration|
    })
<
==============================================================================
COMMANDS                                                *extensions-commands*

                                                                  *:Extensions*
:Extensions             Opens the extensions panel.

==============================================================================
MAPPINGS                                                *extensions-mappings*

`:Extensions` opens a centered floating window: a search bar and plugin
list on the top-left, a live details preview on the top-right that updates
as the cursor moves, and a keymap reference panel docked along the bottom
-- all visible from the moment it opens.

    i           Install the plugin under the cursor.
    x           Remove the plugin under the cursor.
    /           Focus the search bar and filter live as you type.
    <Tab>       Cycle status filter: All / Installed / Not installed.
    r           Reload the catalog and re-render the list.
    q / <Esc>   Close the extensions panel.

==============================================================================
CONFIGURATION                                      *extensions-configuration*

                                                    *extensions-catalog_path*
catalog_path ~
    Type: `string?`, Default: `nil`
    Path to a Lua file that `return`s a custom list of catalog items,
    overriding the small bundled catalog. Each item must have the shape: >lua
        {
          repo = "user/repo",
          name = "display name",
          description = "...",
          category = "...",
          tags = { "tag1", "tag2" },
        }
<
